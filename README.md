# MIPES website

Responsive single-page MIPES product website. The site uses a dark olive visual system, supplied brochure imagery, and concise public-facing copy. Detailed system architecture and specifications are intentionally omitted.

Serve `dist/` with a local HTTP server to review motion and interactions. This repository is source storage only; uploading to GitHub does not publish the website.

## Current interaction

The briefing links lead to a local form that prepares a request for copying. It does not send data or use the placeholder contact address as a destination.

## Logo status

The header uses the approved round M source badge beside the text “MIPES”. The composite header treatment remains pending approval as a logo lockup. The footer uses the supplied reversed logo master on black. See `LOGO_AUDIT.md`.
