# MIPES website

Single-page, responsive, private product site. The page uses approved source imagery from the supplied brochure, concise public-facing copy, the user-selected round M in the header and favicon, and the supplied full-color logo master in the footer. Detailed architecture diagrams and product specifications are intentionally omitted.

Open `dist/index.html` directly, or serve `dist/` with a local HTTP server.
